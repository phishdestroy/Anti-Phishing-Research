# ⚡ Quick Start
## Anti-Phishing Research Tool

### 🚀 Launch in 3 Minutes

### 1️⃣ Unpack the Archive
```bash
tar -xzf anti-phishing-tool.tar.gz
cd anti-phishing-tool
```

### 2️⃣ Install Dependencies
```bash
npm install
```

### 3️⃣ Start the Application
```bash
npm run dev
```

### 4️⃣ Open in Browser
Navigate to: `http://localhost:5000`

## 🎯 First Test

### Step 1: Enter URL
```
https://httpbin.org/post
```

### Step 2: Enter Payload
```
access_key={access_key}&word01={word01}&botcheck={botcheck}
```

### Step 3: Press Buttons
1. Wait for automatic processing 🕒
2. Check the generated values 🧐  
3. Click "Send Request" 📤
4. Watch the logs in real-time 📜

## ✅ Verification

You should see:
- ✅ "Connected" status in the header
- ✅ Generated variables on the right
- ✅ Processed payload
- ✅ Real-time activity logs at the bottom

## 🆘 Troubleshooting

### Port already in use?
```bash
PORT=3000 npm run dev
```

### WebSocket not connecting?
1. Check the firewall 🔒
2. Try a different browser 🌐
3. Temporarily disable your antivirus 🛡️
